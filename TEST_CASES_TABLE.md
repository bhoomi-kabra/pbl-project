## 💡 Viva / Professor Defense: Explaining "Where We Are Lagging"

When presenting this table to your professor:

1. **Why do we have Fails and Partial passes?**  
   *"Sir, industry-standard software testing requires negative boundary tests and vulnerability scans. A project showing 100% pass usually means negative test cases were omitted. Our suite tests real stress conditions, highlighting our current technical roadmap."*

2. **The 3 Core Lagging Areas:**
   - **Input Validation Lag (`TC-FAIL-013`):** Missing `/^[6-9]\d{9}$/` regex enforcement on mobile numbers.
   - **GIS Geofence Lag (`TC-FAIL-014`):** Missing server-side Point-in-Polygon boundary check to reject out-of-city coordinates.
   - **Enterprise Security Lag (`TC-FAIL-015`):** Admin actions protected by UI tab state rather than cryptographically signed JWT Bearer tokens.
